Top: Sentinel is a greybox service made of two kinds of agent. The Orchestrator agent is deterministic: it takes the release candidate trigger, scopes the run, dispatches the pentest agents and applies the gate policy. The Pentest agents are AI agents that decide what to try next based on what they see; the Validator reproduces every finding. Bottom: the six steps for each release candidate. Step 6, Documentation, closes the feedback loop: reports, evidence and developer feedback tune the next run. Clicks 1–2: gate outcomes. Gate thresholds are a proposal; align with the security team's risk policy.

Considerations

Risks and how we address them

Risk spotted! 👀
Mitigated ✓

Release timelines

Agents run in parallel and are time-boxed; scope focuses on what changed in the release

Mitigated ✓

UAT ≠ Production

Track environment parity (config, auth, integrations) so findings reflect production

Mitigated ✓

AI agent safety

Agents locked to UAT targets, no production data, rate-limited, every action logged

Mitigated ✓

Noise and false positives

Validator agent reproduces each finding; humans review criticals before blocking
